# 👟 Nike Responsive E-Commerce Website

A modern and responsive Nike-inspired landing page built using **HTML**, **CSS**, **JavaScript**, and **Bootstrap**.

This project demonstrates front-end development skills including responsive design, DOM manipulation, animations, and interactive user interfaces.

## ✨ Features

- Responsive design for desktop, tablet, and mobile.
- Interactive hero slider.
- Product showcase section.
- Product image gallery.
- Shopping cart interface.
- Size selection.
- Smooth animations and transitions.
- Modern UI inspired by Nike.
